# 2019

I had understood that this was a year that people either loved or hated, based on what you thought about the recurring intcode puzzles.

I did this year over about 4 months in 2026. For me, this was probably my favourite year of all.

Initially, it was charming to have the intcode computer persist between days and adding features to it.
But the amazing part came later. I'm in awe of the programs Eric has managed to create for the intcode computer,
from text adventure games to Breakout. Breakout inspired me to make another [visualisation](https://github.com/gulllberg/advent-of-code-visualisations).

The other days were also good. 22 was an interesting mathematical puzzle, which I ended the year with.
